# Smart Study Planner

Smart Study Planner is a web application designed for students to manage their study schedule and track progress.

## Features

* Add subjects and topics
* Set exam dates
* AI-generated daily study schedule
* Reminder system for tasks
* Track progress (completed / pending topics)
* Show analytics (study time, completion rate)
* AI suggests weak areas and revision times

## Tech Stack

* Next.js (frontend)
* Express.js (backend)
* MongoDB (database)

## Installation

1. Clone the repository
2. Install dependencies using `npm install`
3. Start the server using `node server.js`
4. Open the application in your web browser at `http://localhost:3000`
